# MCP 2.0 Features — Visual Guide

Visual explainer for the released **Model Context Protocol specification `2026-07-28`**. "MCP 2.0" is an informal name for this guide; the normative spec uses date-based versioning.

## Live visual site

https://mcp-2-features-visual.consistentapp.in

## Contents

Nine sections cover the feature landscape, stateless architecture, Multi Round-Trip Requests (MRTR), MCP Apps / Tasks / managed authorization extensions, HTTP routing, caching, authorization, migration, and official references. Includes Mermaid visualizations, tabbed alternative views, search, light/dark mode, diagram zoom and export, and print support.

## Files

- `site/` — generated, self-contained static website and PWA assets.
- `source/visual.json` — editable source for the visual-site generator.

## Preview locally

```bash
python3 -m http.server 8080 --directory site
```

Open `http://localhost:8080`.
